# Diário de sessões

Toda sessão de IA termina com um arquivo `AAAA-MM-DD-<ia>-<tema>.md` aqui.

## Modelo

```markdown
# AAAA-MM-DD — <IA> — <tema>

- Fase: N
- Branch / PR:
- Papel nesta sessão: (implementação, revisão, testes, curadoria...)

## Feito
## Pendente
## Não testado (e por quê)
## Decisões tomadas (com link para ADR, se houver)
```
